Introdução ao CSS

CSS (Cascading Style Sheets) é a linguagem utilizada para definir a aparência visual das páginas web. Permite separar o conteúdo do design, facilitando a manutenção e organização do site.

Tipos de CSS

CSS Inline

Este texto usa CSS inline aplicado diretamente no elemento HTML.

CSS Interno

Este parágrafo usa CSS interno.

CSS Externo

O CSS externo é aplicado através de um ficheiro separado chamado estilo.css.
